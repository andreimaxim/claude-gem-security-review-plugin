How to read—and not overread—this experiment

One fixed upgrade question

The frozen request identifies the exact current and requested gem versions. Rails remained at 7.0.8.7 for the Redis-only runtime comparison.


    
Research quality is separate from transport
The report was classified as insufficient: it missed active Rails.cache callers and exact target-version research. An additional hiredis-option imprecision was minor. Passing cache checks does not make an incomplete report complete.

    
Cost, time and coverage use different units
Session cost is the final cumulative SDK estimate. Worker time comes from the completion event. Harness elapsed time includes the idle period before interruption. Four worker tools and 415 words describe effort, not accuracy.
No percentiles, five-run variation, blinded calibration or controlled model ranking are claimed.

    
Evidence and limits
Raw SDK trace, native session logs, request, manifest, original report and independent runtime observations are retained with checksums. Original execution_failure is preserved; the corrected matcher accepts the saved trace offline.
Redis-only checks passed five tests and 20 assertions under both client versions with matching app observations. There is no frozen Redis positive-issue rubric, and no production safety or performance claim.
